Standardisation Rules

NZ STD v2.3

1. Class Code

Recognised codes are uppercase: 9TAK1, 9TAK2, 9TEA1, 9TEA2, 9MAT1, 9MAT2, 9TAI1, 9TAI2. Fix lowercase (e.g., 9tai2 → 9TAI2). Important: If incomplete (e.g. '9TAI', missing class number), clear/delete the cell completely as the class cannot be identified.

2. Height (cm)

Must be an integer in centimetres (e.g., 162). Convert metres (1.62m → 162) or feet/inches (5'4" → 163). Remove all unit letters.

3. Handspan (cm)

Must be a numeric cm value (e.g., 19.5). Convert millimetre entries (195mm → 19.5). Remove unit labels.

4. Siblings

Integer counts only (0, 1, 2...). Standardise written words (none, zero, - → 0).

5. Broken Bone

Must be exact title case: Yes or No.
Convert numeric values: 1, 2, 3... → Yes and 0 → No.
Fix case errors (yes, NO → Yes, No).
